# API Reference

Base URL: `/api/v1`

- `POST /auth/login`
- `POST /backups`
- `GET /backups`
- `POST /vault/lock/{backup_id}`
- `POST /recovery/plan`
- `POST /simulation/run`
- `GET /analytics/readiness`
- `GET /healthz`
- `GET /openapi.json`

WebSocket:
- `GET /ws/live` live telemetry broadcast channel
